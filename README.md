# Public Passenger Vehicle License Analysis

## 📌 About the Project

This project analyzes the **Public Passenger Vehicle Licenses** dataset from the **City of Chicago**.

The main goal is to understand the characteristics and patterns of Chicago's public passenger vehicle fleet using Python and data analytics techniques.

## 🎯 Objectives

* Load and explore the dataset
* Clean and preprocess the data
* Handle missing and duplicate values
* Perform exploratory data analysis (EDA)
* Analyze data using univariate, bivariate, and multivariate methods
* Create visualizations and interactive charts
* Identify useful insights from the data

## 📊 Dataset

* **Dataset:** Public Passenger Vehicle Licenses
* **Records:** 16,330
* **Columns:** 17
* **Source:** City of Chicago Data Portal
* **Domain:** Transportation

[View Dataset](https://data.cityofchicago.org/Community-Economic-Development/Public-Passenger-Vehicle-Licenses/tfm3-3j95/about_data)
